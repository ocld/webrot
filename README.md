### supported formats

| category | formats | how it rots |
| :--- | :--- | :--- |
| **codebases & configs** | `.ts`, `.tsx`, `.js`, `.py`, `.rs`, `.go`, `.c`, `.cpp`, `.java`, `.astro`, `.css`, `.scss`, `.json`, `.html`, `.yaml`, `.toml`, `.glsl`, `.wgsl`, whole repo folders | syntax-safe coderot (strings, numbers, booleans, hex colors & shader swizzles), auto-skips `node_modules`/`.git`, exports runnable `.zip` |
| **images & graphics** | `.jpg`, `.png`, `.bmp`, `.gif`, `.webp`, `.svg`, `.psd`, `.aseprite`, `.tga`, `.tiff`, `.ico`, `.avif`, `.heic`, `.ppm` | jpeg scan-data bends, png filter-byte warps with crc-32 re-signing, palette, vector & pro pixel bends |
| **music & audio** | `.wav`, `.aiff`, `.mp3`, `.flac`, `.ogg`, `.opus`, `.m4a`, `.aac`, `.caf` | header-safe pcm stutter/crush/melt, mpeg frame shuffle, container-safe payload bends |
| **daws, synths & midi** | `.flp`, `.fst`, `.rpp`, `.mid`, `.sf2`, `.vital`, `.fxp`, `.mmp`, `.mod`, `.xm`, `.it`, `.s3m` | fl studio audio-clip/playlist/note/mixer rot, reaper chunks, soundfont sample bends, vital patch & balanced midi rot |
| **fonts & game roms** | `.ttf`, `.otf`, `.woff`, `.nes`, `.gb`, `.gbc`, `.gba`, `.sfc`, `.n64`, `.nds`, `.md`, `.sav`, `.nbt` | sfnt `glyf`/`kern` warp with opentype checksums, nes chr/prg tiles, game boy rom corrupter with header & global checksum recalculation |
| **video, 3d & docs** | `.mp4`, `.mov`, `.webm`, `.mkv`, `.glb`, `.obj`, `.stl`, `.ply`, `.gcode`, `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.epub`, `.srt`, `.vtt`, `.csv`, `.sqlite`, `.wasm`, any binary | `mdat` datamosh, `BIN` & mesh vertex melt, g-code wobble, zip-xml & length-safe pdf rot, subtitle/csv glitches & header-guarded raw rot |

### modes & shortcuts

`chaos` · `smart` · `block tear` · `pixel sort` · `rgb split` · `melt` · `deepfry` · `tile swap` · `stutter` · `invert xor` · `crush` · `byte flip`

`r` reroll seed · `d` download · `↑↓` switch file · `?` formats · `esc` home
